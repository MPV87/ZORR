# ZORR®

Onepager für die Marke ZORR® (KP Plattner GmbH) – reine Marken- und Produktinfo, kein Shop.

- `index.html` – Startseite mit Zündrad-Navigator durch die Produktwelten
- `impressum.html`, `datenschutz.html` – Rechtliches
- `img/sortiment/` – Produktfotos (WebP), `img/` – Powermatic-Logo
- `fonts/` – Libre Baskerville und Montserrat, lokal eingebunden (OFL-Lizenz)
- `og-image.jpg` – Vorschaubild beim Teilen in Social Media / Messengern

Die ZORR® Powermatic Stopfmaschinen haben eine eigene Website: https://zorr-powermatic.com
